Site Proxy (lightweight)

Enter a URL and choose how to open it. For sites that block embedding (Google, some banks), use "Open proxied page in new tab" so the site loads as a top-level page through the proxy (this bypasses frame-blocking). You can also open via the integrated tProxy implementation by clicking "Open with tProxy" which uses the tProxy handler and its URL encoding.
